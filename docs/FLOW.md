# ทำคลิปวิดีโอด้วย Google Flow

Flow (flow.google.com) ใช้ Veo / Omni ทำวิดีโอ แต่ไม่มี API ให้เรียกตรงๆ (ถ้า API key ของคุณมีโมเดล `veo-*` ก็เรียกผ่าน Gemini API แทนได้ ซึ่งคิดเงินตามวินาที) วิธีนี้จึงสั่งผ่านหน้าเว็บ โดยใช้ [flow-helpers.js](../flow/flow-helpers.js) ช่วยพิมพ์ prompt และดึงไฟล์

## ภาพรวม

```
รูปพี่กะเทย (ตัวละครหลัก)  ──เป็นภาพอ้างอิง──▶  เฟรมแรกของแต่ละช็อต (Nano Banana, 0 เครดิต)
                                                     │
                                                     ▼ Frames → Video (ช็อตละ 6 วิ = 10 เครดิต)
                                              clips/1.mp4 … 4.mp4  ──▶  node pipeline.mjs … video
```

ทำให้คนกับห้องเหมือนเดิมทุกช็อตได้ ต้องใช้สองขั้นนี้คู่กัน:
1. **ทำรูปตัวละครครั้งเดียว** แล้วแนบเป็น ingredient ทุกครั้งที่ทำเฟรมของช็อต
2. **ทำวิดีโอจากเฟรม (Frames)** แทนการพิมพ์ข้อความอย่างเดียว ภาพจะเริ่มจากเฟรมที่เราเลือกไว้ หน้าจึงไม่เพี้ยน

## ขั้นตอน

### 0. เตรียม
- เปิดโปรเจกต์ Flow ในแท็บใหม่ แล้ววาง `flow/flow-helpers.js` ใน Console (หรือให้เบราว์เซอร์อัตโนมัติรันให้)
- ตั้งค่า: **Image → 9:16 → Nano Banana → x2** (โหมดภาพ "Generating will use 0 credits")

### 1. ตัวละคร
พิมพ์ prompt ตัวละครพร้อมฉาก (ดูตัวอย่างใน README) แล้วเลือก 1 ใน 2 รูป ตัวอย่างอยู่ที่ [examples/host/](../examples/host/)

### 2. เฟรมแรกของแต่ละช็อต (0 เครดิต)
ทำทีละช็อต:
1. กด `+` (Add ingredients) แล้วคลิกแถวรูปตัวละคร **คลิกแถวก็แนบเลย** ถ้าเห็นปุ่ม "Add to prompt" ให้ดูพรีวิวก่อนกด
2. `flow.attached()` ต้องได้ id ของรูปตัวละคร
3. `flow.type("Use the SAME woman, same outfit and same room as the reference image. … Shot N: …")`
4. คลิกปุ่มลูกศร (Start generation) **ด้วยเมาส์จริง** เพราะคลิกด้วย JS แล้วไม่ส่ง

ส่งต่อกันได้ 3–4 ช็อตโดยไม่ต้องรอ ตัวอย่างเฟรมอยู่ที่ [examples/frames/](../examples/frames/)

ดาวน์โหลดเฟรมด้วย `flow.images()` แล้วใช้ `curl` (ลิงก์ใช้ได้ราว 6 ชม.)

### 3. วิดีโอ (เสียเครดิต)
1. เปิดเมนูตั้งค่า → **Video → Frames → 9:16 → 720p → 6s → x1** แล้วอ่านบรรทัด "Generating will use **10** credits" ก่อนทุกครั้ง (8s = 12 เครดิต, x2 = จ่ายสองเท่า)
2. กดช่อง **Start** แล้วเลือกเฟรมของช็อตนั้น เลือกเสร็จ `flow.attached()` ต้องได้ id เฟรมนั้น
   - รายการในตัวเลือกเรียงใหม่ทุกครั้งที่ใช้ ต้องดูพรีวิวก่อนทุกครั้ง
3. `flow.type("Handheld phone video. … She does not speak. …")` เขียนการเคลื่อนไหวเป็นลำดับ และใส่ **"She does not speak"** ด้วย เพราะเราจะใช้เสียงพากย์ของเราเอง
4. คลิกปุ่มส่ง แล้วดู `flow.progress()` ว่ามีงานวิ่งตัวเดียวจริง ไม่ได้กดซ้ำ

### 4. ดาวน์โหลดวิดีโอ
ตัวเล่นวิดีโอของ Flow เป็น canvas เลยหยิบไฟล์ตรงๆ ไม่ได้ ใช้วิธีนี้แทน:
1. **โหลดหน้าโปรเจกต์ใหม่** (ลิงก์จะมาตอนเปิดแต่ละคลิปครั้งแรกหลังโหลดหน้า)
2. วาง `flow-helpers.js` อีกรอบ แล้วสั่ง `flow.watchVideos()`
3. คลิกเปิดคลิปทีละตัว แล้วกด Esc กลับ
4. `flow.videos().curl` จะได้คำสั่ง curl ที่ใช้ดาวน์โหลดได้เลย
5. จับคู่คลิปกับช็อตจาก**เฟรมแรก** ไม่ใช่จากลำดับ เพราะลำดับไม่ตรง:
   ```bash
   ffmpeg -ss 0.2 -i v1.mp4 -frames:v 1 v1.jpg
   ```
6. ตั้งชื่อตามลำดับช็อตลงใน `out/<page>__<product>/clips/1.mp4 … N.mp4` แล้วรัน
   ```bash
   FORCE=video node pipeline.mjs floor01 page-baan video
   ```

## ข้อควรระวัง
- **อย่ากดแท็บ Video เพื่อดูราคา** ถ้าไม่ได้ตั้งใจทำวิดีโอ เพราะโหมดจะค้าง และพรอมต์ภาพนิ่งต่อไปจะเสียเครดิตเป็นวิดีโอ ก่อนกดสร้างให้ดูชิปทุกครั้งว่าเป็น `Nano Banana` หรือ `Video · 720p · 6s`
- ถ้าแผงเบราว์เซอร์ถูกซ่อน การคลิกจะค้าง ให้เช็กด้วย JS (`flow.progress()`) ก่อนกดซ้ำ จะได้ไม่ส่งงานซ้ำสองรอบ
- อัปโหลดรูปจากเครื่องเข้า Flow ผ่านเบราว์เซอร์อัตโนมัติไม่ได้ (หน้าต่างเลือกไฟล์) ทุกภาพที่ใช้เป็นเฟรมจึงต้องสร้างใน Flow เอง
- ดูมือ นิ้ว และแผ่นสินค้าทุกคลิป ราว 1 ใน 3 ต้องสร้างใหม่
