# Story mode: คลิปเล่าเรื่องขายของ ตั้งแต่หาสินค้าจนโพสต์ติดตะกร้า

คู่มือนี้คือกระบวนการที่ใช้ทำ 2 คลิปแรกของเพจ **พี่สาวสายถูก** ตั้งแต่หาสินค้า เขียนเรื่อง ทำคลิป ตรวจงาน จนโพสต์ Reel พร้อมตะกร้า Shopee
- กระเบื้องยาง "รีโนเวทห้องยาย ไม่ถึง 400 บาท!" → `examples/stories/tile01/`
- เปลเก้าอี้แขวน "มุมคาเฟ่หลังบ้าน งบ 374 บาท!" → `examples/stories/hammock01/`

## แนวคิด

1. **เรื่องต้องเป็นเรื่องของสินค้าตลอด** เล่าแบบ "ก่อน → เจอของ → วิธีใช้ → ผลลัพธ์ → ราคา/ตะกร้า" ห้ามออกนอกเรื่อง
2. **ขายด้วยความถูก** เปิดคลิปด้วยตัวเลขราคา (hook ≤ 30 ตัวอักษร ภาพแรงที่เฟรมแรก) เช่น "ไม่ถึง 400 บาท!"
3. **พิธีกรคนเดียวทุกคลิป** คือพี่กะเทยเสื้อซาตินชมพู ใช้ `refs/host.jpg` รูปเดียวกันตลอด คนดูจะจำเพจได้
4. **ภาพต้องเนียน หน้าต้องเหมือนเดิม สินค้าต้องตรงของจริง** คลิป AI ทำเรื่องนี้พลาดบ่อย จึงต้องมีขั้นตอนกันพลาด (ข้อ 4–7 ด้านล่าง)
5. **ตรวจเองให้ครบก่อนส่ง** ดูทุกรูป และดูคลิปทีละ 1 วิ (จุดน่าสงสัยดูทีละ ½ วิ) ทั้งคลิปจาก AI และคลิปรวม
6. **บอกตรงๆ ว่าเป็น AI และเป็นลิงก์ affiliate** มีป้ายในคลิป ป้าย AI ของ Facebook และบอกในแคปชันกับคำอธิบายเพจ

## เครื่องมือ

| งาน | เครื่องมือ | ค่าใช้จ่าย |
|---|---|---|
| ภาพอ้างอิงและเฟรมแรก | Nano Banana (`gemini-3.1-flash-image`) ผ่าน `story/story-frames.mjs` | ราว ฿2 ต่อรูป |
| ขยับภาพเป็นวิดีโอ | meta.ai ในแชทเดียวสั่งได้ 3 คลิป คลิปละ 8–10 วิ 720×1280 24fps | สมาชิกราว ฿500/เดือน |
| เสียงพี่กะเทย | Gemini TTS (`gemini-3.8-flash-tts`, เสียง Puck + `voice-style.txt`) ผ่าน `story/story-voice.mjs` | ฟรีวันละราว 100 ครั้ง |
| ประกอบคลิป ซับไทย เสียง | ffmpeg ผ่าน `story/story-assemble.mjs` | ฟรี |
| หาสินค้า ลิงก์ affiliate โพสต์ | Chrome ที่ล็อกอิน Facebook / Shopee / Shopee Affiliate ไว้แล้ว | ฟรี |

ทุกสคริปต์อ่านคีย์จาก `GEMINI_API_KEY` ใน environment ห้ามเขียนคีย์ลงไฟล์

## ขั้นตอน

### 1. หาไอเดียจากคลิปที่วิวเยอะ
- เปิดหน้า Reels ของเพจต้นแบบ เช่น "แต่งบ้านกับ เหมี่ยว" แนวบ้านและสวน แล้วเรียงดูจากยอดวิว
  - คลิปชิงช้าสนาม 1.8 ล้านวิว
  - คลิปแผ่นหลังคา 2.4 แสนวิว
  - คลิปมุ้งครอบเตียง 9.2 หมื่นวิว
- จดแค่ **รูปแบบ**: คลิปสั้น ใช้สินค้าจริงในบ้านหรือสวน แคปชันสั้นแบบ "พิกัด + ลิงก์"
- ไม่ลอกคลิป คน หรือเสียงของเขา ใช้คน ฉาก และเรื่องของเราเอง

### 2. เลือกสินค้าใน Shopee
- ค้นหมวดสินค้าจากไอเดียในข้อ 1 แล้วเรียงตามยอดขาย
- **เกณฑ์เลือก:**
  - ราคาถูกเข้ากับเพจ ส่วนใหญ่ไม่เกินหลักร้อย
  - 4.8★ ขึ้นไป และมีรีวิวหลักร้อย
  - ขายดีต่อเนื่อง ดูจากยอดขายต่อเดือน
  - ถ่ายในคลิปแล้วเห็นผลก่อนกับหลังชัด
- จดข้อมูลจริงจากหน้าสินค้าลง `product.facts` ใน `story.json`: ราคา ขนาด น้ำหนักที่รับได้ สี และจำนวนรีวิว **ห้ามแต่งตัวเลขเอง**
- ดาวน์โหลดรูปสินค้าจาก `down-th.img.susercontent.com/file/<id>` แล้วเลือกรูปที่เป็นสินค้าเดี่ยวบนพื้นขาว
  - ครอปส่วนอื่นออก ทั้งภาพเล็กในรูป ตัวหนังสือ และคน
  - ห้ามใช้รูปวิธีใช้ที่ทรงสินค้าไม่ตรง: คลิปกระเบื้องแรกเพี้ยนเป็นแผ่นยาว เพราะรูปอ้างอิงเป็นกระเบื้องเทาแผ่นยาว

### 3. ลิงก์ affiliate
- ไปที่ `affiliate.shopee.co.th/offer/custom_link` วางลิงก์สินค้า ใส่ Sub_id 1 เป็น `fbreel` แล้วกด "เอาลิงก์"
- ได้ลิงก์รูปแบบ `https://s.shopee.co.th/xxxx` ใส่ลงใน `product.link`

### 4. เขียนเรื่อง (`story.json`)
- **ความยาว:** 6–8 ท่อน (`beats`) รวมราว 45–70 วิ
- **เสียงพากย์ (`vo`):**
  - ใช้สำนวนพี่กะเทย เช่น "ตายแล้วแม่!", "นะแก", "จ้า" ห้ามใช้คำ กู/มึง
  - ตัวเลขเขียนเป็นคำอ่าน เช่น "สามร้อยเจ็ดสิบสี่บาท"
- **ภาพอ้างอิง:**
  - `refs`: ภาพอ้างอิงแต่ละรูป และ `role` ที่บอกว่ารูปนั้นคืออะไรและต้องรักษาอะไรไว้
  - `setup`: ภาพสถานที่ "ก่อน" และ "หลัง" ที่สร้างก่อนเริ่มทำเฟรม "หลัง" สร้างจาก "ก่อน" กับรูปสินค้า จึงได้ห้องเดิม มุมเดิม
- **ช็อต (`shots`):**
  - แต่ละท่อนมี 2–3 ช็อต ภาพจึงเปลี่ยนทุก 3–4 วิ และใช้แค่ช่วงต้นของคลิป AI ซึ่งยังไม่เพี้ยน (ดูข้อ 7)
  - `frame` คือคำบรรยายเฟรมแรก ถ้ามีพิธีกร ให้ขึ้นต้นด้วย "Medium shot (waist up)… face large, sharp" เพราะถ้าหน้าเล็กเกิน AI จะวาดหน้าใหม่
  - `motion` คือท่าขยับ ให้ใส่ "Static camera, no zoom" ทุกช็อต
  - ถ้าสินค้ามีขนาดหรือทรงสำคัญ ให้เขียนย้ำทุกช็อต เช่น "Every tile is a small SQUARE 30x30 cm"

### 5. เสียงพากย์
```bash
node story/story-voice.mjs examples/stories/<id> Puck
```
- สคริปต์อัดทีละท่อน ตัดความเงียบหัวท้ายให้ แล้วบันทึกจำนวนครั้งที่ใช้โควตาลง `tts-quota.json`
- **ถ้าขึ้น ⚠ (อ่านช้ากว่า 7 ตัวอักษร/วิ)** แปลว่า TTS อ่านซ้ำ ให้อัดท่อนนั้นใหม่ด้วย `ONLY=b03 node story/story-voice.mjs …` เจอแล้ว 3 ครั้งจาก 14 ท่อน
- Gemini ส่งไฟล์ WAV ที่มีข้อมูลต่อท้าย ต้องอ่านเฉพาะส่วน data (`pcmOf`) ไม่งั้นจะมีเสียงแซดหัวท้ายทุกประโยค

### 6. เฟรมแรกทุกช็อต
```bash
node story/story-frames.mjs examples/stories/<id>                 # setup ก่อน แล้วตามด้วยทุกช็อต
ONLY=yard-after node story/story-frames.mjs examples/stories/<id> # ทำใหม่เฉพาะรูปที่ระบุ
```
- **ตรวจทุกรูปก่อนไปต่อ:**
  - หน้าตรงกับ host
  - ชุดเดิม (ขาสั้นสีขาว)
  - สินค้าทรงและขนาดถูก
  - ฉากถูกช่วง: ช่วงก่อนรีโนเวทพื้นต้องยังไม่ปู
  - ขาและมือเป็นของผู้หญิงคนเดิม
- รูปไหนผิด แก้ `frame` แล้วสั่ง `ONLY=` ทำใหม่ (ทำใหม่ไป 3 รูปจาก 17)

### 7. ขยับเป็นวิดีโอใน meta.ai
- แนบเฟรมทีละ 3 รูป แล้วพิมพ์ข้อความนี้:
  > ทำวิดีโอ 3 คลิป แยกกัน คลิปที่ N ใช้รูปที่ N เป็นเฟรมแรกเป๊ะ ห้ามเปลี่ยนหน้าคน ห้ามเปลี่ยนสถานที่ ห้ามเปลี่ยนรูปร่างสินค้า แค่ทำให้ภาพขยับนิดเดียว กล้องนิ่ง ไม่ซูม ไม่ตัดฉาก อัตราส่วน 9:16 ไม่มีตัวหนังสือ ไม่มีเสียงพูด สไตล์คลิปมือถือจริง ||| คลิปที่ 1 (รูปที่ 1): `<motion>` ||| …
- **ดึงคลิปลงเครื่อง:** Chrome มักบล็อกปุ่ม Download ของ meta.ai ให้ใช้ `tools/meta-pull/` แทน (ดู README ในโฟลเดอร์นั้น) คลิปจะลงมาตามลำดับที่ตั้งชื่อไว้
- **ตรวจทีละ ½ วิ** เทียบกับเฟรมแรก แล้วจด `take: [วิที่เริ่ม, ความยาว]` ของช่วงที่ยังดีลงในช็อตนั้น
  - meta.ai มักเพี้ยนหลังวินาทีที่ 3–5 เช่น หน้าเปลี่ยน ตัดเข้าภาพใกล้เอง ขาคนเปลี่ยน หรือสินค้าเปลี่ยนสี
  - ช็อตที่เสียตั้งแต่ต้น ให้ทำใหม่ หรือแทนด้วยรูปสินค้าจริงจาก Shopee (`still` + `fit: true`) หรือใช้ช่วงดีของคลิปอื่น (`clip: "b05a"`)

### 8. ประกอบคลิป
```bash
node story/story-assemble.mjs examples/stories/<id> "มุมคาเฟ่หลังบ้าน งบ 374 บาท!"
```
- แต่ละท่อนยาวเท่าเสียงพากย์บวก 0.25 วิ แบ่งให้แต่ละช็อตตาม `take`
- ถ้าช็อตสั้นกว่าเวลาที่ต้องใช้ จะยืดช้าลงไม่เกิน 20% ก่อนค้างภาพสุดท้าย
- ใส่ซับไทยตามเสียงพากย์ ใส่ข้อความ hook 3 วิแรก และใส่ป้าย "ภาพและเสียงสร้างด้วย AI" ตลอดคลิป
- ปรับความดังเสียงไว้ที่ -14 LUFS และลดเสียงพีคด้วย limiter
- **ตรวจคลิปรวมทีละ ½ วิอีกรอบ** และเช็กว่าไม่มีขอบดำ: `cropdetect` ต้องได้ `crop=720:1280:0:0` ทุกเฟรม

### 9. โพสต์ Reel บนเพจ (Chrome)
1. เข้ารหัสสำเนาสำหรับอัปให้ต่ำกว่า 10 MB (ตัวอัปไฟล์ของ Chrome จำกัดไว้): `ffmpeg … -b:v 950k–1350k` แบบ 2 pass
2. สลับไปใช้ Facebook ในนามเพจ แล้วเปิด `facebook.com/reels/create` → อัปคลิป → ใส่แคปชัน
   - แคปชันไม่เกิน 400 ตัวอักษร: hook, ข้อมูลสินค้า 1 บรรทัด, 🛒 ลิงก์, คำถามชวนคอมเมนต์, แฮชแท็ก 4 ตัว และวงเล็บ "(ลิงก์ affiliate · ภาพและเสียงสร้างด้วย AI)"
3. กด **ถัดไป** → เปิด **"เพิ่มป้าย AI"** → กด **"เพิ่มสินค้า"** แล้ววางลิงก์ `s.shopee.co.th/…` ตั้งชื่อลิงก์ แล้วกดบันทึก
   - จะขึ้นแจ้งว่าได้ป้าย "มีสิทธิ์รับค่าคอมมิชชั่น" ตัวเลือกนี้มีหลังเชื่อม Facebook Affiliate Partnerships กับ Shopee แล้ว (หน้า "การสร้างรายได้" → การเป็นพาร์ทเนอร์แอฟฟิลิเอต เจ้าของบัญชีต้องกดอนุญาตเอง)
4. กด **โพสต์** แล้วคอมเมนต์ลิงก์ตะกร้าในนามเพจอีกครั้ง เพราะลิงก์ในแคปชัน Reels มักกดไม่ได้
5. เปิด Reel เช็กว่ามีป้าย "เนื้อหาที่สร้างโดย AI" และมีการ์ดสินค้าหรือป้ายค่าคอมมิชชันขึ้น การ์ดอาจขึ้นช้ากว่าโพสต์หลายนาที

### 10. จดผล
บันทึกลิงก์ Reel ลิงก์ affiliate และสินค้าลงใน `pages.json` → `posts[]` ไว้ดูยอดและเลือกสินค้าครั้งต่อไป
